# SMTP IONOS

Réglage à coller dans Supabase, **Authentication → Emails → SMTP**. Le mot de passe ne va jamais dans ce dépôt.

| Champ | Valeur |
| --- | --- |
| Host | `smtp.ionos.fr` |
| Port | `465` |
| Security | SSL/TLS |
| Username | l'adresse email complète |
| Password | secret externe, hors dépôt |

Nom d'expéditeur conseillé : `Nom de l'app by JavaChrist`.
